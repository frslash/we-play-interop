# What these files are

`inwove/project.json` and `inwove/README.md` are the room's own entry for the DTG interop board (Project-Weave-Tech/dtg-interop), written to the board's rules at board commit `af997a1` so that they can be copied into `projects/inwove/` as they are. Each status says what the room's code shows and no more, and each evidence link points to a file in this repository. The room keeps no personal names, so the README names roles where the board's other examples name people: this is a difference the room keeps on purpose.

The room agrees them the way it agrees anything: a person or agent proposes a change in the room, members vote, and the agreed text is committed here. Nothing in this folder is sent to the board by the room. The purpose sentence, whether and when to register, and who commits the entry are left to the room's members.

They reach the board by a commit from someone with write access to it (copy the folder to `projects/inwove/`, run the board's own `npm run validate` there, commit with a message such as `inwove: first entry`), or, without write access, by a pull request or an issue on the board's repository with the two files attached. The evidence links use `blob/main`, so they work once the pull requests that add those files are merged.
